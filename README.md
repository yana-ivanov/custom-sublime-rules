# Custom Sublime Rules

Detection rules for [Sublime](https://github.com/sublime-security/sublime-platform),
written from my own research and maintained as a rule feed.

Rules that are broadly applicable get submitted upstream to
[sublime-security/sublime-rules](https://github.com/sublime-security/sublime-rules).
This repo holds the rest: narrower lures, specific brand impersonations, and
detections still collecting evidence.

## Using this feed

Add this repository as a rule feed in your Sublime instance. Rules sync
automatically and can be enabled individually.
